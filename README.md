# ASM NextGen Technical Campus website

Open `html/home.html` with VS Code Live Server (or another local HTTP server). The pages load their JSON content with `fetch`, which browsers block when files are opened directly from disk.

Pages are in `html/`, styles in `css/`, scripts in `js/`, content data in `data/`, and image assets in `image/`. The site uses plain HTML, CSS, JavaScript, and JSON.

Main pages: Home, About, Campus, Courses & Programs, Departments, Faculty, Admissions (`addmission.html`), Placements, and Contact.
